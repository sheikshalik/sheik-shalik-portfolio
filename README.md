# sheik-shalik-portfolio

Personal academic portfolio for S. Sheik Shalik, ready for GitHub Pages.

## Files

- `index.html` — the complete responsive portfolio page.
- `assets/rice-field-hero.jpg` — locally stored cinematic rice-field artwork used by the page.
- `assets/sheik-shalik-portrait.png` — your supplied portrait, used in the opening section.

## Replace your portrait later

The opening section now uses the portrait you supplied. To use a different photograph later, replace `assets/sheik-shalik-portrait.png` and keep the same filename. The page clips the image into a circular composition with CSS; adjust `object-position` or `clip-path` in the `.portrait-photo` rule in `index.html` if a future image needs a different crop.

## Publish with GitHub Pages

1. Upload `index.html`, `README.md`, and the complete `assets` folder to the root of the `sheik-shalik-portfolio` repository.
2. Replace the existing `index.html` when GitHub asks.
3. Commit the files to the branch used by GitHub Pages.
4. After Pages finishes publishing, open `https://sheikshalik.github.io/sheik-shalik-portfolio/` and refresh the page.

The CV is not included in the website files and there is no CV download link or public editing control.
